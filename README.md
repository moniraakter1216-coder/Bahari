# বাহারি — Marketplace

বাংলাদেশের জন্য multi-category marketplace-এর runnable V1 frontend.

## Requirements
- Node.js 18.17+ (20 LTS recommended)
- npm

## Run

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে http://localhost:3000 খুলুন।

## Current V1
- বাংলা-first responsive UI
- Search
- Category filtering
- Product cards
- Wishlist state
- Cart state
- Dark mode
- Sell/Post-ad modal
